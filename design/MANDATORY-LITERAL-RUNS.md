# Mandatory literal runs across regex barriers

This optional 0.3.3 filter extends the earlier [fixed literal group subset](GROUPED-LITERAL-QUERIES.md). It keeps the existing required-gram array, UTF-16 alphabet, source identity and original regex verification. `rare(_hit)?` requires `rare` even when its suffix is absent. `rare.*hit` requires the two separate runs `rare` and `hit`; it does not require a continuous `rarehit` substring.

The accepted grammar consists of ordinary literal atoms, escaped punctuation, plain or `(?:...)` groups, dot, and `?` / `*` on the immediately preceding complete atom or group. The single existing outside `^` / `$` anchors remain supported. An iterative stack reduces each group to facts: either its entire fixed text, or a list of mandatory fixed runs separated by unknown spans. Adjacent wholly fixed children concatenate. Every dot or optional child ends that concatenation. A `?` or `*` child contributes no facts at all because zero occurrences can match. This also drops all inner facts in `foo(needle.*tail)?bar`, leaving only `foo` and `bar`.

The proof is inductive over those facts. Literal atoms match their fixed text. A fixed group concatenates fixed children. Every successful sequence contains the mandatory runs of all its unquantified children, and each maximal adjacent fixed sequence appears continuously. A dot cannot establish text. A zero-minimum child establishes nothing. Thus every gram drawn from the remaining runs appears in every native match; choosing only the capped subset admits extra candidates and cannot exclude a true match. No concatenation crosses an optional or variable span, even if some particular match consumes zero characters there.

`+`, brace quantifiers, character classes, alternation, named/modifier/lookaround groups, backreferences, character/boundary escapes, leading or doubled/lazy quantifiers, internal anchors and all flags still return `null` for the whole pattern. This is an admission limit, not a user regex rejection: the original scanner remains authoritative. Empty unquantified groups may join fixed neighbors; quantified empty groups are conservative barriers. Under no flags, a quantifier applies to one UTF-16 atom, including an emoji's low surrogate, which the tests explicitly exercise.

Work remains bounded by 4,096 source units, 64 group levels and 128 distinct required trigrams. The whole pattern is validated before any gram cap is applied. Fewer than three units in every mandatory run returns `null`. No format, public contract, catalog, eager missing-object diagnostic or default activation changes.

The prerequisite mechanism used exact current source and a generated 512-file, 16 MiB corpus. The native `rare(_hit)?` query read all 512 sources; manually proven `rar` / `are` conditions passed through the real bounded cohort reader retained only the actual matching file, preserving the complete FaceResult hash and all 512 eager metadata checks. That fixture establishes selective opportunity, not implemented-parser timing. Final production before/after evidence is separate and must retain dense-query and unsupported-pattern costs.

Seventeen cases include exhaustive native-match-to-gram witnesses over variable barriers, 2,000 seeded Unicode optional subtrees, false-bridge examples, unsupported tails after the gram cap, and original fixed/group/flag/depth controls.
