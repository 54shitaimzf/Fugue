# 品牌件

这个仓库里露面的标：标记（几何）+ 宋体字标（竖排），正反各一份。

| 文件 | 用途 |
|---|---|
| `fugue-lockup.svg` | 标记 + 竖排「赋格」。README 顶部那一张 |
| `fugue-lockup-inv.svg` | 同一份，墨色反白成 `#FFFFFF`——深色主题用它 |
| `fugue-mark.svg` | 只要标记的那一处 |
| `fugue-mark-inv.svg` | 反白版 |

## 用它的四条

- 墨色只有一处 `#17181A`（反白版是 `#FFFFFF`）：换色改这一个值，别在别处再定义一份。
- 四周留白 ≥ 半个笔画宽，别把别的元素贴到笔画上。
- **24 px 起**才读得清。更小的那一档（favicon · 列表里的头像）换单向的合流版：真源那份
  `fugue-mark-01-heliu.svg` 在维护者的文档工作区，出图一条命令 `MARK=fugue-mark-01-heliu sh render.sh`。
- 别拉伸、别加圆角、别加阴影、别描边：标记是 32×32 整数格上的纯几何图形（方头收笔、笔画 4 · 净空 ≥ 4），
  字标是 `Noto Serif SC` wght 400 的原轮廓，两者都按原样用。

## 真源

标记与字标在维护者的文档工作区 `assets/icons/`（构造数字 · 候选 · 渲染脚本 · 判据来源都在那儿）。
这个目录里是**发布用的副本**：改标先改真源，再复制过来——两处不要各自改。
