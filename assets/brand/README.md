# 品牌素材

赋格的标志由两部分组成：一个装在方框里的几何图形（下面叫「标记」），和竖排的宋体字「赋格」。每种都有深色和浅色两个版本。

| 文件 | 用途 |
|---|---|
| `fugue-lockup.svg` | 完整标志：方框里的标记加上竖排的「赋格」。方框的高度和文字的高度完全一样。README 顶部用的就是这个 |
| `fugue-lockup-inv.svg` | 同上，但颜色反转成白色 `#FFFFFF`，用在深色背景上 |
| `fugue-mark.svg` | 只有标记，没有文字 |
| `fugue-mark-inv.svg` | 只有标记的白色版本 |

## 使用规则

- **颜色只定义一次。** 深色版只用一种颜色 `#17181A`，白色版是 `#FFFFFF`。要换颜色，只改文件里这一个值，不要在别的地方再定义一遍。
- **留出空白。** 标志四周至少留出半个笔画宽的空白，其他元素不要贴得太近。
- **最小 24 像素。** 比这更小就看不清了。如果需要更小的尺寸（比如网站图标、列表里的小头像），请改用简化版的「合流」标记。它的源文件 `fugue-mark-01-heliu.svg` 在维护者的文档工作区里，用这条命令生成图片：`MARK=fugue-mark-01-heliu sh render.sh`。
- **不要改动图形。** 不要拉伸，也不要加圆角、阴影或描边。标记是在 32×32 的网格上画的简单几何图形（笔画末端是方的，笔画宽 4，四周留白至少 4）；文字用的是 `Noto Serif SC` 字体、字重 400 的原始字形。两者都要原样使用。

  完整标志外面的方框也是设计的一部分，已经画在文件里了，不要自己再加一圈框。它的具体尺寸是：画布 88.32 × 54.84；方框外边高 49.84，等于竖排文字的高度；线宽 3.2；方框内的格子正好是标记 32 格网格的 1.3575 倍。

## 源文件在哪

标记和文字的源文件在维护者文档工作区的 `assets/icons/` 目录里，设计用的尺寸数据、备选方案、渲染脚本和设计依据也都在那里。

这个目录里只是**发布用的副本**。要修改标志，请先改源文件，再复制到这里，不要两边分别修改。
