## 一 · 摘要

**这一份要回答什么。** 0.4.3 要把 TUI 做成「事件通道的客户端」，同时把外观与布局一次做厚。
开工之前要定的不是"好看不好看"，而是：**屏幕上放谁 · 放几行 · 每一行说人话还是说行话 ·
终端认不出那些字的时候退成什么样**。十问里八问是看代码与实测读数回答的，两问是这一版新加的
（界面用词 · 复杂计划怎么给外行看）。

**三句结论。**

1. 那份好看的草稿（PR #54）值得学的是**构造方式**，不是它的样张——排版一层 · 上色一层 ·
   名单从既有常量推 · 不可见字节进门就转义且转义在量宽之前 · 每一条「逐字节相同」都配一条
   「真有东西」。照这五样做，三档（无色 / 黑白属性 / 256 色）是**结构上的必然同形**，不靠逐档对着调。
2. 屏幕上今天有**两件事是给实现者看的**：一批内部量（`跳步` · `拒` · `边界` · `动作` 那一族），
   以及一串原始编号（`契约 r1.implement.1 · 轮次 r1 · 归属 agent/r1/1`，`src/ui/read.ts:384`）。
   第二编给逐行的改法；第三编给「复杂计划怎么缩成几行给外行看」的做法与它今天在路线图里的位置。
3. 「退化」在本站是两件事：**颜色**一张四级表（第 0 级是既有门，`--no-style` 与 `NO_COLOR`
   逐字节全关），外加**字形**一条新档（缺省只许用「内核内建 ∩ console-setup」那一小撮：
   单双线框 22 个 · `░▒█` · `←↑↓→` · `▶` · `•` · ASCII）。路线图 0.4.3 行有两句要按这个读数改
   （逐句与读数见 § 五）。

**判据（前端那一批怎么排先后）。** 三条产品原则——**简洁易用 · 帮助用户注意重要信息 · 轻松**——
在本项目里有一个更早的说法：**机器吵、用户静**（界面是"替用户承担成本"这条立意的脸面）。
把它落成四条可执行的排序规则，用来判"这一格要不要留、要不要上色"：

1. **一屏只留三类东西**：① **该你动的**（门口）② **正在发生的**（在飞的那几格）③ **刚发生完的结果**（收尾一行）。其余降级或收掉。
2. **颜色只标"要不要你管"**：绿 = 成 · 红 = 败 / 被拦 · 黄 = 在等（等你或等机器）· 亮黑 = 弱化。八格表已经是这个形状，照它，不新造格。
3. **能出结论就不出过程**：一个数字进主面的条件是"它能改变你的下一步"；不能的（`跳步` · `拒` · `边界` · 用了哪个工具）进详情面。
4. **默认不出现**：**零就不印** · **无读者的不印** · **同一件事只留一个词** · 不安慰话。凡"每次都要确认一眼"的东西，都不许常驻。

**反过来的一句判词**：界面上任何一处**需要解释自己**的地方，都是没做干净——改法是收掉它，
不是加句子。

## 五 · 三处更正与它们的读数原文

这三处是"不看证据就不知道错在哪"的那一类：规格里原来那几句都写得很顺，而实际读数是反的。
要改的规格句与依据都照抄在下面。

### 5.1 · sparkline：四档 → 三档 + 一个空格位

**要改的规格句（路线图 0.4.3 行原文）：**

> 读数 sparkline（近 N 轮成本小条形——控制台档走 `░▒▓█` 四档，CP437 认得，不用 ▁▂▃）

**哪里不对。** 「CP437 认得」是对的（微软官方 CP437 表在 `0xB2` 给的就是 `▓`），错在把
"CP437 认得"当成了"控制台认得"。

**读数原文**（`readings/linux-console-font-coverage.txt`，8 份 console-setup 字体逐份跑；
`▓` 在每一份的缺席名单里）：

```
=== Lat15-Fixed16
    ABSENT  (8/41): ▀, ▄, U+2581, U+2587, ▓, U+21D2, ►, ✓
=== Lat15-VGA16
    ABSENT  (8/41): ▀, ▄, U+2581, U+2587, ▓, U+21D2, ►, ✓
=== Uni2-Terminus16
    ABSENT  (7/41): ▀, ▄, U+2581, U+2587, ▓, ►, ✓
=== Uni3-Terminus16
    ABSENT  (7/41): ▀, ▄, U+2581, U+2587, ▓, ►, ✓
```

（`░` `▒` `█` 8 份全在；`▓` 8 份全不在。Terminus 那两份多一个 `⇒`，与本节无关。）

**对照另一档**（`readings/linux-kernel-console-map.txt`，内核内建 `cp437.uni` 逐码点检索）：

```
U+2591     0xb0	U+2591
U+2592     0xb1	U+2592
U+2593     0xb2	U+2593
```

——`▓` 在内核内建那一档有、在 console-setup 那一档没有。**`$TERM=linux` 这一个值对应两种字形集，
而环境里没有信号能区分**（console-setup 是用户态的选择）。

**改法**：四档改成「空格 · `░` · `▒` · `█`」——四个可区分的级，把 `▓` 那一格换成空格。

**改主意条件**：内核内建那一档被确认为唯一目标环境时，`▓` 可以回来。

### 5.2 · 控制台图片地板：删「控制台也有图看」

**要改的规格句（路线图 0.4.3 行原文，半块位图那一段）：**

> 半块位图档（chafa 式 PNG→降采样→最近色→`▀▄` 序列，插在 none 与 kitty/sixel 之间的**全平台档**
> ——控制台也有图看）

**读数原文**（同一份文件，`▀` 与 `▄` 那两条）：

```
    ABSENT  (8/41): ▀, ▄, U+2581, U+2587, ▓, U+21D2, ►, ✓
```

——`▀`(U+2580) 与 `▄`(U+2584) 在 8 份 console-setup 字体里**一份都没有**，只在内核内建那一档可达。

**改法**：删掉「控制台也有图看」，改写成一档说明——**控制台没有这一档：图片在控制台上的地板
是文件名那一行**。半块档在终端模拟器里仍可行（字体由用户给，探测不了，与字形档同一条理由），
但它得**降级链完整**：24 位色 → 240 色 → 16 色 → 无色 → 文件名那一行。

**改主意条件**：同 5.1。

**一处没核到的**：这一次没核到 `▀`(U+2580) / `▄`(U+2584) 这两个具体码位在 chafa 源码里的落点
（`chafa/chafa-symbols.c` 抓取失败，404）。"半块＝前景上半、背景下半"是通行做法，本文**没有**
一个可引用的官方出处——落笔实现前自己确认一次。

### 5.3 · 跳步那一栏：撤掉「恒印 0」这件待批件

**路线图原来记的待批件：**

> 跳步那一栏恒印 0（「没有跳步」与「栏不见了」如今长得一样；负数已会原样印出，剩的是样式——
> 采纳要动 `ui/term.test.ts` 黄金帧 7→8 行，改主意条件写在 `src/probe/status.ts` 的 `skipsNote` 说明里）

**读数原文**（`src/probe/status.ts:140–156`，今天产品里那一处唯一的定义源）：

```ts
/**
 * 跳步那一栏的字。**两张读脸都从这里取**（命令行的 `linesOf` 与 TUI 的 `ui/frame.ts`）：
 * ...
 * **对照那一支说 0 也该印**（远端那一支恒印「图上 N 步」，健康那趟也是一个数）——**这一条没采纳**：
 * 采纳它左栏长 4 个字符，`ui/term.test.ts` 的黄金帧从 7 行顶到 8 行（就是那一档折行的位置），而那条
 * 期望不是「事件加栏」带来的移动，本站不许自己动它。**改主意的条件**：人批一次显示层的期望移动
 * （同 ③ 那一次，出处要写在提交信息里）。
 */
export function skipsNote(skips: number): string {
  return skips === 0 ? '' : ` · 跳步 ${skips}`
}
```

**两处断言各钉着一档**：`src/ui/term.test.ts:119`（今天那一份小账画出来 7 行）·
`src/ui/frame.test.ts:197`（图外那一档不印跳步）。

**读出来的**：**产品今天的行为就是「零就不印、非零才报」**；那件待批件要的是反过来的「恒印 0」，
而它自己写着**没采纳**。

**改法**：按判据（规则 4 零就不印）**撤掉这件待批件**——今天已经是那个样子，所以这一件
**不动显示层、不动那 7 行黄金帧**，也不进 § 六 1 那四件。跟着要做的只有一件事：把 `skipsNote`
说明里那句「改主意的条件＝人批一次显示层期望移动」随施工撤掉（注释件，不是显示层）。

**改主意条件**：出现一个"每次都要看见图上几步"的读者（那时它进处境视图，不进对话面）。
