# 0.3.1 增量：派生索引落盘与损坏重建

叠在 [格式 v1](blob-index-format.md) 上。产品查询尚未接线；这一步提供独立存储
帮助模块，不改 Truth/View/Log 契约，不生成新的权威日志，不声称阶段二结束。

`createBlobIndexStore(root)` 提供两条路：

- `read(blob)`：只读 `.fugue/idx/v1/<前2位>/<完整ID>.json`；缺失、损坏、不同版本、
  危险目录/文件、权限和 IO 故障都是 null，不修文件、不创建目录
- `rebuild(blob, bytes)`：从真实原字节核 Git 内容地址、重新构建，再原子替换；
  返回 `{index, stored}`。构建无效/超预算给 null；磁盘缓存不可用仍可给有效的内存结果。
  stored 为 true 要求文件、分片与每层缓存目录链接的父目录 fsync 都成功，不是「已经接上搜索」的意思

## 文件边界

工作区根在构造时解析为绝对路径一次，之后 cwd 的变化不能改落点。Linux 实现
逐层打开真实目录，后续通过自己持有的目录描述符定位。只接受属当前
UID、非组/其他人可写的控制目录。新目录 0700，文件 0600；不自动改既有权限。
最终文件必须是单硬链接的普通文件，软链/特殊文件不跟随；读取加 nonblocking，
预算最多 8 MiB+1，读时大小/时间戳变动即 miss。已有超大的普通缓存文件无需读
原内容就能被可信重建替换。其他危险叶保持原样，外部目标不会被改。

创建目录时同步它的父目录（并发创建已存在时也同步），最后再同步完整分片。
写入用随机唯一临时文件、exclusive/no-follow 创建、文件 fsync、rename、目录
fsync；失败清自己的临时对象，不清别人的数据。并发同 blob 重建只发布完整的
canonical 记录，没有一半内容的目标文件。读者可能因并发更换读到 miss，照退档。

不持长期 fd，不拿产品 writer 锁。不支持描述符路径的环境只缺少磁盘缓存，
**不是移植/隔离成功声明**。记录自身有预算，当前单元**没有全缓存磁盘配额、
跨 blob 淘汰或恶意同 UID 进程隔离**；目录权限检查也不认证主动伪造的合法表。
持久缓存属于受控构建派生物，校验和只检测损坏，不把缓存升格为真源。

## 验证

```sh
node tools/test-entry.js fast src/search/index-store.test.ts src/search/index-format.test.ts
node tools/check-targets.js
node tools/check-events.js
```

断言：缺失读不创建目录；私有记录往返；损坏读不修→可信重建等价；软链/硬链
指向一份**格式合法**的外部记录也不能被接受；共享可写目录拒绝且不改权限；
无效 ID/错内容地址无写；过大记录有界 miss 后修复；并发读写只见完整结果，
结束后不留临时文件。源内容、Git/M0、模型协议、沙箱策略、网络权限均不变。
